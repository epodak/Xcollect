# Xcollect CLI — Local Retrieval and Optional Cloudflare Decisions

Feature branch: `feature/retrieval-decision-cli`. Minimum Python 3.10, no external Python dependencies.

## Local CLI (does not need Cloudflare)

```bash
git fetch origin
git switch feature/retrieval-decision-cli
python -m xcollect_cli --source local --data data/xcollect.json search "Opus 5.5"
python -m xcollect_cli --source local --data data/xcollect.json search "jev" --json
python -m xcollect_cli --source local --data data/xcollect.json read 1234567890
python -m xcollect_cli --source local --data data/xcollect.json export "Grok Bot" --out exports/grok-bot
```

`data/xcollect.json` is generated by the *real Local Profile sync*. The CLI **will not silently use seed data** if no real local data file exists. For a local seed fixture in tests, explicitly pass `--data path/to/fixture.json`.

The export bundle includes `README.md`, `manifest.json`, `sources.jsonl`, and `posts/*.md`. Markdown prefers `body_raw` and labels snippet fallback. Export preserves the canonical input and emits zero model-generated claims.

Lexical search currently supports case-insensitive NFKC substrings and explicit aliases for `Opus 5.5`, `Jev`, and `Grok Bot`. **It does not yet provide embeddings, typo-tolerant fuzzy search, generated summaries, or external X trend search.** Queries are limited to 200 characters; result pages max 100.

## Cloud read mode

The Worker requires a dedicated secret token:

```bash
pnpm exec wrangler secret put XCOLLECT_API_TOKEN
# On CLI machine, use the OS secure secret store or an untracked environment variable:
export XCOLLECT_API_BASE="https://your-protected-host.example"
export XCOLLECT_API_TOKEN="your-private-api-token"
python -m xcollect_cli --source cloud search "Claude Opus 5.5"
python -m xcollect_cli --source cloud read 1234567890
python -m xcollect_cli --source cloud export "jev" --out exports/jev
```

For Windows PowerShell use `$env:XCOLLECT_API_BASE` and `$env:XCOLLECT_API_TOKEN`. Avoid passing tokens via `--token` (may be recorded in process lists/history). No direct D1 or Wrangler management credentials go into the CLI.

**Mandatory deployment protection**: The old `/api/tweets` and `/api/feed` routes remain outside v1 bearer authentication; Cloudflare Access must protect the entire hostname, including old API routes, and unintended `workers.dev` access must be disabled or equivalently protected. Do not deploy a public personal instance without this.

API contract:

- `GET /api/v1/search?q=...&limit=20`: `{"success":true,"scope":"bookmarks_only","query":"...","total":N,"results":[{"score":80,"item":{...}}]}`
- `GET /api/v1/items/<id>`: `{"success":true,"item":{...}}`
- `POST /api/v1/decide`: `{"id":"<id>","model":"clef-flash"}`. Response is `{"success":true,"decision":{"answers":...,"usage":...,"model_id":...,"source_id":...}}`.

All v1 endpoints require `Authorization: Bearer <XCOLLECT_API_TOKEN>`, and fail closed if the secret is not configured. This uses a bounded in-memory scan of the Bookmark Plane for the first vertical slice; it is not the final D1 FTS5 implementation.

## AI decision opt-in

`config.toml` contains:

```toml
[decision]
enabled = false
allow_jev = false
```

To permit explicit Cloudflare Clef decisions, set `enabled = true`, regenerate `src/_config_data.py` using `python scripts/sync_config.py`, and deploy using the existing Cloudflare workflow. This can use the account's Workers AI free Neurons allowance where eligible; availability and limits vary. To enable **third-party Jev** deliberately, also set `allow_jev = true` (Jev is metered).

```bash
python -m xcollect_cli --source cloud decide 1234567890 --model clef-flash
python -m xcollect_cli --source cloud decide 1234567890 --model jev
```

A decision is a judgment about source characteristics, not an article summary, fact-check, embedding, or a ranking score to blindly merge into existing behavioral learning.

## Acceptance

```bash
python scripts/check_retrieval.py
pnpm run check
```

For production verification also test Cloudflare Access, a missing/incorrect bearer token, actual D1 bookmarks, Worker Python `env.AI.run`, and token/AI quotas. Those tests require live infrastructure; offline tests cannot certify the cloud deployment.
